### [R1-1][Medium][scripts/check-patterns.mjs:50]
NG の理由に出す `lastLine()` が出力の最終行を返すため、sync / build の拒否(捕捉されない例外)では常に `Node.js v22.x`、import では「上のエラーを参照」になり、CI のログから原因が読めない。前提チェック(166 行)も同じ。
**修正方針:** `Error:` で始まる行を優先して拾い、無ければ `Node.js v…` とスタックの行を除いた最後の行を出す。

### [R1-2][Medium][scripts/check-patterns.mjs:72-136]
既存の検査の多くにケースが無い(テスト欠落)。sync の patterns / categories が配列でない、categories の形、slug・category の形、未知の status、title / description_for_ai / block_map / tone_tags の型、content_schema / properties / required の形、enum が配列でない、maxLength が整数でない(1.5)。import の format 検査、`--allow-removed` で受け入れる場合、version の変更の表示も無い。CLAUDE.md の「検査を足したらケースを足す」の前提が導入時点で満たされていない。
**修正方針:** 検査ごとにケースを 1 行ずつ足す。build の「ブロックの部品名との衝突」は、パターンの部品名が必ず `Pattern` + 1 文字以上になり、いまのブロックの部品名とは重ならないので、ケースを作れない(対象外)。

### [R1-4][Medium][scripts/check-patterns.mjs:18-25]
